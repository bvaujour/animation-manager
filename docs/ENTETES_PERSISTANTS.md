# En-têtes persistants

- Le titre « Tableau de bord » de l’espace animateur utilise désormais la couleur de texte principale et reste lisible sur le fond clair.
- Tous les véritables en-têtes de page utilisent une règle commune `position: sticky`.
- Ils restent visibles en haut pendant le défilement sans sortir du flux, donc sans recouvrir le contenu.
- Le fond est opaque et la bordure basse est identique sur ordinateur et téléphone.
- Deux comportements seulement sont conservés : ordinateur à partir de 800 px et téléphone sous 800 px.
