# Page autonome Temps de travail

- La rubrique est accessible directement depuis le rail de direction.
- La page Planning ne contient plus de troisième onglet Temps de travail.
- La page affiche uniquement la sélection des périodes, les jours comptabilisés, les réunions et le télétravail/préparation.
- Le tableau « Jours comptabilisés » est calculé avec le même service que le récapitulatif de paie.
- Les réunions et préparations restent modifiables et supprimables depuis cette page.
