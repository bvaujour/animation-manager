# Réactivation de l’onglet Temps de travail

L’onglet n’avait pas été supprimé : son template, son JavaScript, ses API, ses modèles, sa migration et ses tests étaient toujours présents.

La correction force les trois onglets de Planning à rester visibles dans une grille de trois colonnes, sur ordinateur comme sur téléphone.

Accès direct possible : `/planning/?mode=temps-travail`.
